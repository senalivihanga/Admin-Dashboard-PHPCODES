# 🏠 Department of Railways - Quarter Management System

A web-based application for managing government quarter applications for Sri Lanka Railway employees.

## 📌 Features

- **User Authentication** - Secure login system
- **Quarter Applications** - Submit and track applications
- **Waiting List Management** - View position in queue
- **Status Tracking** - Monitor approval progress
- **Notifications** - Receive real-time updates
- **Profile Management** - Update user information
- **Offer Response** - Accept/Deny quarter offers
